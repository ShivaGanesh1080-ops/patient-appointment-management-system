WTMP Viva Cheat Sheet
1 The 3-Tier Architecture

Built as a decoupled 3-tier system: Semantic HTML5/CSS3/Tailwind Single Page Application (UI), an asynchronous Node.js & Express.js REST API layer, and an ACID-compliant SQLite database using Write-Ahead Logging (WAL) for high-speed concurrent access.

2 Dynamic Slots & Concurrency Lock

The server dynamically computes 30-minute intervals from doctor clinic hours. To prevent double-booking race conditions, the database locks slot combinations; if two users book the same slot simultaneously, the 2nd request is cleanly rejected with HTTP 409 Conflict.

3 Full Clinical Lifecycle

Covers the complete medical flow: 12 credentialed Indian doctors across 6 specialties, instant printable token passes with QR verification, patient cancellation with medical audit notes that immediately frees slots, and a doctor consultation desk.

Under the Hood Trace: User Selects Slot ➔ Native Fetch POST /api/appointments ➔ Express Middleware (Phone & Date Validation) ➔ SQLite Unique Check & Insert ➔ HTTP 201 Created + Thermal Slip Display
